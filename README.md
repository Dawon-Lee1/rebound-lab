# Rebound Lab

Rebound Lab helps fantasy baseball players find hitters likely to bounce back (or regress) next season.
It blends Statcast expected stats (xwOBA) with actual results and splits each hitter's projected change into **Luck** and **Regression** to the league average.
The site is a static Astro build with no accounts, no cookies, and no betting content.

## Structure

| Path | Contents |
| --- | --- |
| `analysis/` | Python pipeline. `model.py` holds the formula; `04_projection.py` picks parameters; `05_build_json.py` writes the site data |
| `analysis/results/model_params.json` | Chosen parameters (w, k), read by `05_build_json.py` |
| `site/` | Astro static site |
| `site/src/data/players.json` | Season totals and scores for the site (generated by `05_build_json.py`) |

## Run

```bash
pip install -r analysis/requirements.txt
python analysis/04_projection.py   # picks w, k → analysis/results/model_params.json
python analysis/05_build_json.py   # → site/src/data/players.json
cd site && npm install && npm run build
```
